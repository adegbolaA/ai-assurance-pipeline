# CHAP — Required Documentation

Applicants must provide proof of identity, proof of income for every household member over 18, and a signed lease or rental agreement for the residence.

Applications are processed within 30 calendar days of receipt of a complete file. There is no fast track; every application follows the same review process and is decided by a caseworker.

If documentation is missing, the caseworker sends a request for information and the 30-day processing clock pauses until it is received.
